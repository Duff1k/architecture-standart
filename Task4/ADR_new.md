### <a name="_bjrr7veeh80c"></a>**Альтернативы**
Мы рассматривали вариант ручной выгрузки ставок сотрудниками бэк-офиса и рассылки по почте. Такой вариант слишком подвержен человеческим ошибкам и не масштабируется при ежедневных изменениях ставок.
Также рассматривался вариант построения прямой интеграции API между партнёрским колл-центрами, но партнёр не готов поддерживать API, поэтому остановились на файловом обмене.
Был вариант загружать ставки в отдельный справочник в системе кол-центра вручную, но это увеличило бы трудозатраты и риск ошибок, поэтому реализуем автоматическую синхронизацию.

**Недостатки, ограничения, риски**
- Необходимость поддержки надёжного и безопасного канала передачи файлов.
- Риск несвоевременной доставки файла (почта/SFTP может задержать доставку).
- Возможные проблемы синхронизации версий ставок, если файл не обновится вовремя.
- Увеличение нагрузки на PRS при массовых запросах от кол-центра. Требуется кэширование.

Набор задач

## Сервис ставок
- **API ставок**
    - Реализация REST API `/rates` (JSON) для чтения ставок из системы кол-центра.
    - Тесты на производительность (SLA < 300 мс).
- **Модуль экспорта ставок**
    - Автоматическая генерация файлов (CSV/Excel) при изменении ставок и по расписанию.
    - Логирование версии файла и истории выгрузок.
- **Модуль уведомлений**
    - Уведомление ответственных сотрудников о неудачной передаче (e-mail/Slack).
- **Кэширование**
    - Встроенный кэш ставок для защиты БД от пиковых нагрузок.

## Система кол-центра
- **Интеграция с системой ставок**
    - Разработка сервиса синхронизации ставок (с запросами к `/rates`).
    - Локальный кэш на стороне КЦ (чтение раз в N минут).
- **UI операторов**
    - Доработка карточки клиента — отображение ставок в реальном времени.

## Партнёрский кол-центр
- **Интеграция через файлы**
    - Приём и импорт CSV/Excel по защищённому каналу.
    - Регламент обновления и формат файла (спецификация).
- **Обучение операторов**
    - Инструкции по работе с выгрузками и консультациями клиентов.

## Инфраструктура
- **Канал передачи файлов**
    - Организация SFTP-сервера или зашифрованной почты.
    - Настройка расписания выгрузок и мониторинга успешности передачи.
- **Мониторинг и логирование**
    - Метрики SLA для API, ошибок выгрузки, задержек доставки.

## Бэк-офис депозитов
- Обновление ставок через Admin UI PRS.
- Тестирование автоматической генерации файлов для партнёров.
