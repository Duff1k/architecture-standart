| F8     | Ведение истории заявок, статусов, ставок.                                                  | Для контроля SLA.                            |

| U3     | Поддержка доступности для пожилых клиентов.                                                | Основная аудитория банка.                    |

| R1     | Доступность 99,9%, работа 24/7.                                                            | Требование бизнеса.                          |
| R2     | Переключение на резервный ЦОД.                                                             | Отказоустойчивость.                          |
| R3     | Горизонтальное масштабирование интернет-банка.                                             | Рост нагрузки.                               |
| R4     | Исключение прямой нагрузки на АБС.                                                         | Защита производительности АБС.               |
| R5     | Логирование и аудит действий.                                                              | Соответствие комплаенсу.                     |

| P1     | Отклик операций в миллисекундах.                                                           | UX критичен.                                 |
| P2     | Высокая пропускная способность для массовых заявок.                                        | Пики нагрузки.                               |
| P3     | Кэширование справочников и ставок.                                                         | Снижение нагрузки на АБС.                    |
| S      | Поддерживаемость (Supportability)                                                          |                                              |
| S1     | Использование существующих технологий (MS SQL, Oracle, .NET, Java).                        | Снижение стоимости сопровождения.            |
| S2     | Возможность расширения решения на другие продукты.                                         | Подготовка к развитию.                       |
| S3     | Документация для разработчиков и бизнеса.                                                  | Поддержка развития.                          |
| S4     | Мониторинг и алертинг SLA.                                                                 | Эксплуатация 24/7.                           |
| +R     | Ограничения (Restrictions)                                                                 |                                              |
| +R1    | Шифрование трафика (HTTPS/TLS).                                                            | Чувствительные данные (ФИО, телефон).        |

| +R3    | Готовность к интеграции с Kafka.                                                           | Переход на событийную архитектуру в будущем. |
